# USDJPY Analysis Chart

## 起動
1. `data/` に `USDJPY_M1_YYYYMM.csv` を置く
2. `python3 python/build_data.py`
3. `python3 run.py`
4. ブラウザで `http://127.0.0.1:8000`

## 時刻の扱い
CSV の `time` は MT5 サーバー時刻として、その表示上の年月日時分をそのまま保持します。
ブラウザのローカルタイム（JST等）への自動変換はしません。

## 期間表示
日・月・年を選んでも全データをチャートから削除しません。表示範囲だけを移動します。
そのため「日」で 10/10 を表示したあと、左へスクロールして 10/9 以前を見ることができます。
